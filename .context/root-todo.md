## 目的

- The Session 上での練習を補助するツールを、サイトを離れず利用できるようにする
- MVP として The Session 上に常時利用できるメトロノームを実装する

- v0.1.2 ではメトロノームの音響品質を改善し、実際の演奏中に試聴・比較しながら正式な音色パラメータを決定する
- v0.1.2 の音色を実機で比較評価し、無演奏時・楽器演奏中・音源再生中の聞こえ方と歪みを確認する

- 再調整後の試聴結果を踏まえ、音色ごとの役割が重複しない構成へ整理する。`Wood` の改善と `Beep` の埋もれやすさ・役割の重複を確認し、`Crisp`・`Sharp`・`Wood` の3音色に確定する

- 本ファイルの内容は自動更新されうるため、正本マージは手動で行う
- v0.1.0 は Firefox 拡張として実装する
- v0.1.1 の README・CHANGELOG・manifest 版数・配布 ZIP の作成が完了している
- v0.1.1 には、最後の The Session タブ終了時に音が停止しない不具合の修正が含まれる

- JavaScript 構文・manifest JSON・パッケージ内容の検証が完了している
- 音源をページ DOM やポップアップに依存させない
- ABC 解析や伴奏機能は将来構想であり、v0.1.0 には含めない
- Firefox 拡張の署名・配布先は Mozilla Add-ons（AMO）とする
- AMO の配布方式は Unlisted（非公開配布）と Listed（一般公開）から選択する。Unlisted は署名済み XPI を直接配布する用途に適している
- 署名済み拡張は通常版 Firefox / Beta に導入する。AMO への提出時は ZIP の直下に `manifest.json` がある構成とする
- 初回の署名申請は AMO の Web 画面から行う方法を基本とし、必要に応じて `web-ext sign --channel=unlisted` による CLI 署名も利用できる
- アップデート時は同じアドオン ID を維持し、`version` を上げて同じ AMO 登録へ新しいパッケージを提出する
- AMO 提出に必要な `browser_specific_settings.gecko.data_collection_permissions` を追加し、データ収集・送信を行わない拡張として `required: ["none"]` を宣言する
- `data_collection_permissions` は Firefox Desktop 140、Firefox for Android 142 から対応するため、`strict_min_version` との整合性を取る必要がある
- 最低対応版を Desktop 140／Android 142 に引き上げる方針を候補とする。実際の配布対象を確認したうえで、Android 対応設定を含めるか判断する
- Firefox で無効な `"windows"` 権限と、未実装の `browser.windows.onBoundsChanged` リスナーは削除する。非アクティブ判定には `windows.getAll` と `windows.onFocusChanged` を使用する
- 最後の The Session タブやウィンドウを閉じた際の停止判定では、イベント直後のタブ一覧のずれや競合に注意する。閉じるタブ ID を明示的に除外して残存タブを判定し、ウィンドウ終了時も停止対象として扱う
- 最後の対象タブがなくなった場合の停止判定は background 側で行い、競合しやすい `pagehide` 経由の停止通知には依存しない
- v0.1.2 の修正方針はルートの `v0.1.2修正方針.md` に整理されていた。音響改善の実装、実機試聴を踏まえた3音色構成（`Crisp`・`Sharp`・`Wood`）への整理、README・CHANGELOG・リリース ZIP の更新が完了した。最終的な実演奏時の試聴評価と AMO 提出は未完了
- v0.1.2 では既存音色のエンベロープ・周波数・出力を調整し、比較用に `Crisp`（矩形波）を追加した。実機試聴で不採用と判断した `Click` とノイズ生成コードは削除済み
- v0.1.2 では、音量150%・拍頭アクセント時も各音源のピークが1未満となるよう調整した。実際の出力で歪みが発生しないことは実機で確認する必要がある
- v0.1.2 の manifest は `0.1.2` に更新し、README と CHANGELOG も更新済み
- v0.1.2 の配布 ZIP `the-session-tools-0.1.2.zip` を最終3音色構成で更新済み。JavaScript 構文、manifest JSON、差分の空白エラー、ZIP 内容・版数の静的検証が完了している
- v0.1.2 の音響改善では、正式な音色パラメータの判断に実機での比較試聴を必要とする。未評価の音色を聴感上の優劣で決めつけず、The Session での実際の利用環境で評価する
- 音響改善では一度に一要素だけを変更し、波形・周波数・長さ・減衰・level を個別に比較試聴する
- 初期音量は控えめにし、実際の The Session での演奏中に評価する
- Wood の最大音量・アクセント時は、以前の設定値では `0.55 × 1.5 × 1.25 = 1.03125` 相当のピークとなる問題があった。v0.1.2 では各音源のピークが1未満となるよう調整済みだが、実際の再生で歪みがないか確認する

- 試聴結果を受け、`Click` の削除、初期音色の `Crisp` への変更、`Beep`・`Wood` の再調整を実装済み。`Beep` は 880 Hz・遅めの立ち上がり・低めの出力へ、`Wood` は 720 Hz へ調整した。音色表示順は `Crisp` / `Sharp` / `Beep` / `Wood` とした
- 再調整後の実機試聴で `Wood` の聞き取りやすさが改善したことを確認済み
- `Beep` は実機で若干埋もれやすく、改善後の `Wood` と音色の役割が近いことが判明したため、削除する方針を決定し、プリセットから削除済み
- v0.1.2 の最終候補は `Crisp`・`Sharp`・`Wood` の3音色。保存済みの `Beep` 設定は、次回起動時に無効な音色として扱われ、`Crisp` へフォールバックする
- `Beep` 削除後の v0.1.2 配布 ZIP を更新・検証済み。構文・manifest・差分・`Beep` の残存なしを確認済み。3音色構成での実演奏時の最終試聴は未完了
- v0.1.2 の README・CHANGELOG・ToDo・リリース ZIP を最終3音色構成に合わせて更新済み。README には旧 `Beep`／`Click` 設定から `Crisp` へ自動移行する内容を記載し、CHANGELOG に最終音色構成と削除内容を明記した

## MVP ゴール

- The Session 上に小型メトロノームを常時表示する
- BPM を変更できる
- Play / Stop ができる
- ページ遷移・タブ切替中も再生を継続する
- ブラウザが非アクティブ・背面・最小化中は最大5分再生し、その後は再生希望を維持して音だけを停止する
- 最後の The Session タブを閉じたときに再生を停止する
- 最後に設定した BPM を保存する

- v0.1.2 の音色について、無演奏時・楽器演奏中・音源再生中の聞こえ方と歪みを実機で評価する
- 実機評価を踏まえて音色構成を整理し、`Click`・`Beep` を削除するとともに `Wood` を再調整する
- `Crisp`・`Sharp` を有望な採用候補として扱い、実機評価の結果を踏まえて正式な音色構成と初期音色を決定する。初期音色は `Crisp` に変更済み
- `Wood` の改善を実機で確認済み。`Beep` は埋もれやすく `Wood` と役割が近いため削除済み。`Crisp`・`Sharp`・`Wood` の3音色構成に確定し、実演奏時の最終評価を経て正式な音色パラメータを確定する

- 初期音色は `Crisp` に変更済み。正式な音色構成は `Crisp`・`Sharp`・`Wood` の3音色に確定済み。実演奏時の最終評価を行い、正式なプリセットパラメータを確定する
- 正式プリセットの波形・周波数・長さ・減衰・level は、実機での比較試聴と実際の演奏中の評価を経て決定する

## 実装設計メモ

- UI層（content script）: `[[[https://thesession.org/*](https://thesession.org/*)](https://thesession.org/*)](https://thesession.org/*)`と`[[[https://www.thesession.org/*](https://www.thesession.org/*)](https://www.thesession.org/*)](https://www.thesession.org/*)`にのみ注入する。UIの表示と入力送信だけを担当し、音声・再生状態を保持しない。ページ遷移後はbackgroundから状態を再取得する。
- 再生層（MV3 background event page）: `AudioContext` とタイマーを保持する唯一の音源ホスト。短い Oscillator/Gain のクリックを先読みで予約し、画面の可視性やcontent scriptの寿命から切り離す。
- 状態: `{ bpm, volume, sound, subdivision, userWantsPlayback, audioActuallyPlaying, autoResume }`をbackgroundで管理する。`bpm`・`volume`・`sound`・`subdivision`・`autoResume`は`storage.local`に保存する。再生希望はブラウザ再起動後に復元しない。UIは読み込みのたびに状態を取得して描画する。
- 非アクティブ時: The Sessionが非アクティブになってから5分後、`userWantsPlayback`を維持したまま音だけを止める。アクティブ復帰時は`autoResume`が有効なら自動再開する。タイマーはgenerationを照合し、復帰後に古いcallbackが停止しないようにする。
- 終了条件: ユーザーのStop要求、または`tabs.query`でThe Sessionタブが0件になった場合は再生希望を解除して停止する。タブ終了イベント直後の一覧に閉じるタブが残る場合を考慮し、閉じるタブ ID を明示的に除外して判定する。ウィンドウ終了時も停止判定を行い、`pagehide` 経由の停止通知には依存しない。
- AMO提出設定: `browser_specific_settings.gecko.data_collection_permissions.required`に`["none"]`を設定する。Firefoxで未対応の権限・イベントを使用せず、非アクティブ判定は対応済みの`windows.getAll`と`windows.onFocusChanged`を利用する。`data_collection_permissions` の対応開始バージョンに合わせ、配布対象に応じた `strict_min_version` を設定する。
- v0.1.2 音響改善: 既存の `SOUND_PRESETS` のエンベロープ・周波数・出力を調整し、`Crisp`（矩形波）を追加済み。実機試聴では `Crisp`・`Sharp` が有望、`Click` はシャカシャカしたノイズ感があり不採用、`Beep` は割れ・ノイズ感、`Wood` は低すぎて聞き取りにくい可能性があると判明した。`Click` とノイズ生成コードは削除済み。`Crisp` を初期音色に設定し、`Beep` は 880 Hz・遅めの立ち上がり・低めの出力へ、`Wood` は 720 Hz へ再調整した。その後、`Beep` は実機で埋もれやすく `Wood` と役割が近いことから削除し、正式候補を `Crisp`・`Sharp`・`Wood` の3音色に確定した。保存済みの `Beep` 設定は `sanitizeSound` により `Crisp` へフォールバックする。README・CHANGELOG・ToDo とリリース ZIP は最終3音色構成に合わせて更新・静的検証済み。3音色での最終的な実演奏評価と正式パラメータの確定を残している。波形・周波数・長さ・減衰・level を一度に一要素ずつ比較し、実際の The Session での演奏中に評価する。
- 音量・アクセント: `volume` は最大150%の設定を維持しつつ、プリセットの `level` と拍頭アクセントの組み合わせで出力段の歪みが発生しないか確認する。v0.1.2 では各音源のピークが1未満となるよう調整済み。必要性が確認された場合にリミッターを検討する。
- ノイズ系 Click: 短い `AudioBufferSourceNode` を音源として実装していたが、実機試聴でシャカシャカしたノイズ感があり、不採用と判断した。音色プリセットおよび関連実装から削除済み。
